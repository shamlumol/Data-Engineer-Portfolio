# Data Engineer Portfolio - Client Project

A modern, responsive portfolio website built for a data engineer client to showcase projects, professional experience, and technical skills.


---

## Project Overview

This portfolio was developed for a client in data engineering to effectively present their expertise, project portfolio, and professional journey. The site features a clean dark theme with smooth animations, expandable project cards, and comprehensive project case studies.

Built with React and modern web technologies, this portfolio demonstrates:
- Professional UI/UX design
- Complex state management
- Dynamic content rendering
- Responsive layouts
- Performance optimization

---

## Key Features



**Typewriter Hero Section** : Animated introduction with gradient text 
**Tabbed About Section** : Organized personal info, experience, education, skills 
**Expandable Project Cards** : Click to reveal detailed project information 
**Category Filtering** : Filter projects by type (Data Analytics / Database Development) 
**Pagination** : Browse through 10+ projects with intuitive navigation 
**Fully Responsive** : Optimized for all devices from mobile to desktop 
**Dark Theme** : Professional gradient backgrounds with sparkle hover effects 
**Contact Integration** : LinkedIn and email links with smooth animations 

---

## Technologies Used

### Frontend
- **React 19** - UI library with hooks for state management
- **React Router DOM 7** - Navigation between pages
- **React Bootstrap** - Responsive grid system
- **React Icons** - Icon library for social media and contact links
- **AOS (Animate on Scroll)** - Scroll-triggered animations
- **CSS3** - Custom styling, gradients, and animations

### Development Tools
- **Vite** - Fast build tool and development server
- **ESLint** - Code linting for consistent style
- **Git** - Version control
